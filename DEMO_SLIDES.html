The Clinical Challenge in the Emergency Ward

Why Progressive Gated Reasoning Beats Single-Turn Summarization

Status Quo Pain Points

Fragmented Signals & Cognitive Overload

  • Scattered Longitudinal Context: Outside urgent-care scripts, held hospital meds, and unreviewed send-out labs sit in separate EHR silos.
  • Hidden Brand/Generic Hazards: Patients combine OTC brand Tylenol with leftover generic Acetaminophen, or take CYP3A4 inhibitors over statins.
  • Premature Diagnostic Closure: Chasing infections before ruling out drug toxicity—or missing a local RSV/Flu/COVID surge in the patient's ZIP code.
Our Architecture

Physician-in-the-Loop 4-Stage Diagnostic Funnel

  • Stage-Gated Investigation: Drug & outbreak checks unlock in clinical order so attending physicians validate each hypothesis layer.
  • Deterministic + Agentic Verification: Combines live NIH RxNorm, OpenFDA SPL/FAERS, and CDC ZCTA5/NSSP/NWSS APIs with Google ADK synthesis.
  • Dedicated Symptom Mapping Panel: Visually separates resolved vs. unexplained symptoms at every stage with bedside Confirm / Rule-Out controls.

Production Engineering

Agent Efficiency & Defense-in-Depth Security Architecture

Performance & Agent Efficiency

Sub-Second Warm Reads & Single-Call Audits

  • Single-Flight FHIR Deduplication (6x → 1x): Per-patient in-flight locks + 90s TTL cache collapse parallel agent reads into 1 GCP Healthcare call (<0.1 ms warm).
  • 1-Call Batch Drug Audit: audit_patient_medications_rxnorm_openfda audits full regimens in parallel threads instead of 6–8 sequential LLM turns.
  • Parallel 4-Feed ZIP Radar: Concurrent ZCTA5 + NSSP ED + NWSS Wastewater + AQI cuts cold lookup latency by >60%.
  • Pooled Sessions & Singleton Runner: Shared OAuth2 AuthorizedSession + singleton ADK InMemoryRunner.
Security & PHI Protection

Cloud Run IAP + CWE / OWASP Hardening

  • Identity & Least Privilege: Cloud Run Native IAP (--iap) + dedicated physician-assist-sa (read-only FHIR + Vertex AI User only).
  • SSRF & Injection Guards: Strict leading-alphanumeric FHIR regex + ".." rejection (CWE-22/918), Lucene sanitization & WGS84/FIPS SoQL validation.
  • Zero PHI Exfiltration: HTTP body redaction in logs (CWE-532) & public HAPI fallback disabled (ALLOW_PUBLIC_HAPI_FALLBACK=false).
  • Sandbox & Prompt Isolation: Swimlane CSP: connect-src 'none' + OWASP LLM01 untrusted clinical text boundaries.
